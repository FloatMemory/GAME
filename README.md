# 零点之后：午夜旅馆

这是一个可直接运行的中文恐怖游戏单文件版本，适合在浏览器中打开体验。

## 玩法

- 使用 WASD / 方向键移动。
- 按 E 互动：拾取记录、拿钥匙、捡电池、躲进柜子。
- 按空格开启或关闭手电，手电会持续耗电。
- 找到 3 张值班记录，并拿到房间钥匙以后，前往出口离开旅馆。
- 敌人会在你收集到记录后开始追逐；躲进柜子可以暂时躲避它。
- 按 P 暂停 / 继续；窗口失焦时自动暂停。

## 运行方式

- 直接双击 `index.html` 打开，或者用浏览器打开该文件。
- Windows 可直接运行 `开始游戏.bat`。
- macOS / Linux 可运行 `开始游戏.sh`。

## 当前版本特点

- 单文件结构，部署简单。
- 包含多个可交互物件：记录、钥匙、电池、柜子、出口。
- 扩展版地图和敌人推动逻辑。
- 更完整的恐怖氛围、状态 HUD 与重开机制。
