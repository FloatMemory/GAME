# 零点之后：午夜旅馆

一个无需安装或构建工具、直接在浏览器运行的中文恐怖游戏原型。

## 开始游戏

打开 `index.html` 即可游玩。桌面浏览器和手机触屏均可运行。

## 玩法

- 使用 **WASD** 或方向键在旅馆里移动。
- 靠近物品或柜子后按 **E** 调查、拾取或躲藏。
- 按 **空格** 开关手电；注意电量，也可以寻找备用电池。
- 找到三张值班记录，避开追来的东西，最后找到出口。
- 手机屏幕下方提供方向键、调查和手电按钮。

## 当前内容

包含六个可探索房间、三条叙事线索、可补充的手电电池、可躲藏的衣柜、会追踪玩家的幽灵，以及收集全部记录后解锁的出口。游戏使用原生 Canvas 和 JavaScript 绘制，不依赖外部资源。
