# 零点之后：午夜旅馆

**快速试玩版：**双击 `index.html`，用浏览器打开即可。无需安装、联网、构建工具或外部素材；整个游戏都在这一个文件里，Windows/macOS/Linux 均可直接运行。

## 操作

- 移动：`WASD` 或方向键；手机使用画面下方方向按钮。
- 调查、拾取电池、进入/离开柜子：靠近后按 `E`；手机按「调查 E」。
- 手电：空格键或手机「手电」按钮。电池耗尽后只能通过拾取备用电池补充。
- 暂停/继续：`P`。切换窗口时自动暂停。

## 目标

在旅馆中找到三张值班记录，避开会追踪你的东西，靠近出口并按 `E` 离开。手电会持续耗电；找到备用电池，并利用衣柜躲避追逐。

## 发布/拷贝

最轻便的发布方式就是把 `index.html` 单独发给玩家，下载后双击即可玩。也可将 `index.html` 和本 README 一起压缩成 ZIP；游戏运行不需要压缩包或额外依赖。
